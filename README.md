
# Config Translator

CLI-транслятор собственного конфигурационного языка в TOML,
реализованный на Python.

## Возможности

- Разбор конфигурационного языка.
- Поддержка имён, чисел и строк.
- Поддержка массивов и комментариев.
- Вычисление константных выражений.
- Генерация TOML.

## Структура проекта

- `src/` — исходный код.
- `tests/` — автоматические тесты.
- `run.bat` — запуск в Windows.
