# Config Translator

CLI-транслятор собственного конфигурационного языка в TOML,
реализованный на Python.

Проект предназначен для обработки конфигурационных данных.
Пользователь вводит настройки на собственном языке, а программа
выполняет лексический и синтаксический анализ, вычисляет выражения
и преобразует результат в формат TOML.

## Возможности

- Чтение конфигурации из стандартного ввода (stdin).
- Чтение конфигурации из файла.
- Лексический анализ входного текста.
- Синтаксический анализ и проверка корректности конструкций.
- Поддержка имён, двоичных чисел и строк.
- Поддержка однострочных комментариев.
- Поддержка массивов, в том числе вложенных.
- Поддержка арифметических выражений.
- Поддержка операции поиска минимального значения `min()`.
- Использование ранее объявленных констант в выражениях.
- Вычисление выражений во время трансляции.
- Генерация результата в формате TOML.
- Вывод результата в стандартный поток вывода (stdout).
- Вывод сообщений об ошибках в stderr.

## Используемые технологии

- Python 3.12
- TOML
- Модуль `unittest` для автоматического тестирования.

## Синтаксис конфигурационного языка

### Имена

Имя начинается с латинской буквы и может содержать латинские
буквы и цифры.

```text
port: 0b10100000;
serverName: @"Main server";
```

### Числа

Поддерживаются двоичные целые числа.

```text
first: 0b101;
second: 0B1100;
```

### Строки

Строки записываются с использованием символа `@` перед
двойными кавычками.

```text
name: @"Application";
message: @"Hello, world!";
```

### Комментарии

Однострочные комментарии начинаются с `||`.

```text
|| Server configuration
port: 0b10100000;
```

### Массивы

Массивы начинаются с `#(` и заканчиваются `)`.
Элементы разделяются запятыми. Поддерживаются вложенные массивы.

```text
ports: #(0b101, 0b110, 0b111);
nested: #(0b1, #(0b10, 0b11));
```

### Выражения

Выражения записываются в префиксной форме с использованием `?{}`.

Поддерживаются операции сложения `+`, вычитания `-`
и поиска минимального значения `min()`.

```text
first: 0b101;
second: 0b11;
sum: ?{+ first second};
difference: ?{- first second};
minimum: ?{min(first, second)};
```

В выражениях можно использовать ранее объявленные константы.

## Пример работы

Входные данные:

```text
port: 0b10100000;
workers: 0b100;
name: @"Main server";
ports: #(0b10100001, 0b10100010);
nextPort: ?{+ port 0b1};
minimumPort: ?{min(port, 0b10100001)};
```

Результат трансляции:

```toml
port = 160
workers = 4
name = "Main server"
ports = [161, 162]
nextPort = 161
minimumPort = 160
```

## Запуск программы

Для работы требуется установленный Python 3.12 или новее.

### Запуск с чтением из файла

Из корневой директории проекта:

```bash
python main.py tests/server.conf
```

Для второго примера:

```bash
python main.py tests/game.conf
```

Результат трансляции выводится непосредственно в консоль.

### Запуск с вводом из консоли

Запусти программу без аргументов:

```bash
python main.py
```

Введи конфигурацию, например:

```text
port: 0b10100000;
workers: 0b100;
name: @"Main server";
```

Для завершения ввода в Windows нажми `Ctrl + Z`,
затем `Enter`.

В Linux и macOS используется `Ctrl + D`.

После завершения ввода программа обработает конфигурацию
и выведет результат в формате TOML.

## Запуск тестов

Для запуска всех автоматических тестов выполни команду
из корневой директории проекта:

```bash
python -m unittest discover -s tests -p "test_*.py" -v
```

Также можно использовать:

Windows:

```bash
run.bat
```

Linux и macOS:

```bash
bash run.sh
```

Тесты проверяют:
- распознавание токенов;
- обработку чисел, строк и комментариев;
- обработку массивов и вложенных конструкций;
- синтаксический анализ;
- вычисление арифметических выражений;
- обработку некорректного ввода;
- трансляцию конфигурационных файлов.

## Обработка ошибок

При обнаружении синтаксической ошибки программа выводит
сообщение с описанием проблемы и завершает работу
с ненулевым кодом возврата.

Сообщения об ошибках выводятся в stderr, а результат
трансляции — в stdout.

## Результат проекта

В результате разработан CLI-транслятор собственного
конфигурационного языка в TOML.

Программа выполняет полный цикл обработки входных данных:
от лексического анализа до генерации итоговой конфигурации.
